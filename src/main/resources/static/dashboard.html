PUBL_SERVC_ID 공공서비스아이디 고유 식별자 추출 (중복 수집 시 자동 UPDATE 기준키) notice_id (PK)
PUBL_SERVC_JURSDCTN_INST_NM 소관기관명 시흥 또는 경기도 포함 필터링 (타 30개 시·군 제외) dept
PUBL_SERVC_PURPS_DTCONT 목적상세내용 정규식 HTML 태그 제거 및 AI 토큰 최적화(1,500자 제한) clean_content
LAST_UPD_DE 최종수정일자 YYYYMMDD ➡️ YYYY-MM-DD 포맷 변환 및 NULL 결측치 보정 posted_date

2. Zero-PII(개인정보 무수집) 행동 컨텍스트 기반 DB ERD

MySQL 8.0 Schema 
erDiagram
    NOTICES ||--o{ BEHAVIOR_LOGS : "열람/클릭 대상"
    NOTICES ||--o{ CONTEXT_NOTICE_MATCHES : "AI 분석 대상"
    ANONYMOUS_CONTEXTS ||--o{ BEHAVIOR_LOGS : "실시간 행동 기록"
    ANONYMOUS_CONTEXTS ||--o{ CONTEXT_NOTICE_MATCHES : "맥락 맞춤형 추천"

    NOTICES {
        varchar notice_id PK "PUBL_SERVC_ID"
        varchar title "공공서비스제목"
        varchar dept "소관기관명(시흥/경기)"
        varchar posted_date "수정일(YYYY-MM-DD)"
        varchar support_type "지원형태내역"
        text clean_content "정제된 본문(AI 입력)"
        varchar ai_category "AI 분류 카테고리"
        text ai_summary "AI 3줄 요약"
    }
    ANONYMOUS_CONTEXTS {
        char context_id PK "익명 세션 UUID v4"
        json active_filters "선택된 관심 태그"
        json recent_keywords "최근 검색 키워드"
        varchar inferred_persona "AI 추론 탐색 의도"
    }
    BEHAVIOR_LOGS {
        bigint log_id PK "로그 고유번호"
        char context_id FK "익명 세션 UUID"
        varchar notice_id FK "대상 공고 ID"
        varchar event_type "VIEW / BOOKMARK / SEARCH"
        int dwell_time_sec "체류 시간(초)"
    }
    CONTEXT_NOTICE_MATCHES {
        bigint match_id PK "매칭 고유번호"
        char context_id FK "익명 세션 UUID"
        varchar notice_id FK "공고 고유번호"
        boolean is_matched "적합 여부"
        int match_score "적합도 점수(0~100)"
        varchar match_reason "행동 기반 AI 추천 사유"
    }
